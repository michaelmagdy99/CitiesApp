# 🌍 City Explorer

A Jetpack Compose Android app that displays a list of cities with alphabetic fast-scroll and map integration.

## ✨ Features

- 📍 View a list of cities grouped by the first letter
- 🔤 Alphabet index sidebar for fast navigation
- 🗺️ Click any city to open its location in **Google Maps**
- 🧭 Uses `geo:` URI scheme for launching map activity
- 📦 Built with **Jetpack Compose**, **Kotlin**, and **Material Design**
